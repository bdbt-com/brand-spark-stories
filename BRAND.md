# BDBT / Daily Wins brand rules

Set once here. Use these everywhere on the new pages.

## Colour
| Token | Value | Use |
| --- | --- | --- |
| black | `#000000` | Page background |
| `coal` | `#11100E` | Panels and cards |
| white | `#FFFFFF` | Headlines and body text |
| `ash` | `#A8A196` | Secondary text. Also the Daily Drift side of any comparison |
| `gold` | `#C29B62` | The Daily Win. Primary buttons, the win side of a comparison, key numbers |

Gold has one meaning: the Daily Win. Don't use it as decoration.

## Type
One family: Archivo (variable, self-hosted via `@fontsource-variable/archivo`).
- Headlines: `font-display`. Condensed width, weight 800, upper case, tight leading. This matches the YouTube thumbnails.
- Body: `font-sans`. Normal width, weight 400 to 600, sentence case.
- No italics. No tracked-out small caps labels above headings.

## Layout
- Left aligned. One idea per section: a headline, one or two lines, then one visual.
- Panels use `rounded-lg`. Buttons use `rounded-md`.
- Motion is limited to: the Wins and Drifts lines drawing, numbers counting up, the page backdrop warming as you scroll.

## Writing
- No dashes used as punctuation.
- No "it's not X, it's Y" lines.
- No three-item lists for rhythm.
- No filler openers. No hype words.
- Plain British English that sounds like Ben talking.
- Never invent prices or event dates. Leave a clear placeholder.
